1. Casos artificiais

Placa fabricada (sem dados de pacientes) com resposta conhecida para cada regra crítica: comparação, decisões automáticas, NT, API MAC, dosagem, DRB3/4/5, resultado final, modo só NGSengine, consenso, REDOME, LD e o próprio sistema de gabarito. Rodam sozinhos ao abrir esta página.

2. Corridas reais conferidas (gabaritos)

Arraste o gabarito (*_gabarito_validacao.json, gerado na aba Exportar do app depois de conferir a corrida) junto com os arquivos originais da corrida (XML, Excel do Assign e, se houver, a lista do REDOME). Dá para soltar vários gabaritos e corridas de uma vez. A corrida é refeita do zero, com as mesmas decisões, e cada célula é comparada com o que você conferiu. Nada sai do seu computador.
Solte aqui os gabaritos e os arquivos das corridas
.json, .xml, .xlsx, .zip, .csv
